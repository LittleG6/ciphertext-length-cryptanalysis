Language carries structure at several levels. Letters do not occur with equal frequency, common pairs appear again and again, and words follow patterns that readers learn without conscious effort. A statistical model can record part of this regularity by counting short sequences of characters. When a candidate sentence contains familiar sequences, the model gives it a better score. When a sentence contains unlikely combinations, the score becomes worse. Such a model is limited, but it provides a useful objective function for a search algorithm.

A substitution cipher replaces every letter by one fixed alternative. The mapping is a permutation, so two different plaintext letters never share the same ciphertext letter. Spaces may remain visible even though the letters have changed. The number of possible keys is far too large for direct enumeration over the full alphabet. Practical cryptanalysis therefore searches only a small part of the key space and uses language statistics to decide which directions appear promising.

Hill climbing is one simple search method. It starts from an initial key, exchanges two assignments, and retains the new key when the candidate plaintext receives a higher score. A single climb can become trapped at a local optimum, so the procedure starts again from many independently chosen keys. The best distinct candidates across all restarts form a ranked archive. More restarts usually improve coverage, while longer climbs allow more local exploration. Both choices increase computational cost.

Text length changes the evidence available to the scoring model. A short message may contain only a few repeated patterns and may not use every letter. Several incorrect keys can therefore produce plausible looking candidates. A longer message offers more observations, more repeated n grams, and more constraints on the mapping. Even then, a finite search algorithm can miss the correct key. Information theoretic identifiability and practical algorithmic recovery are related questions, but they are not the same question.

Reliable experiments separate training documents from test documents. The training material estimates language probabilities, while unseen test passages supply plaintext samples. Each trial draws a fresh passage and a fresh random key. The experiment records the correct candidate rank, character accuracy, key accuracy on observed symbols, score difference, search cost, and elapsed time. Repeated trials make it possible to report uncertainty rather than a single favorable example.

Top k evaluation recognizes that a useful system may return a short list rather than one answer. A human analyst or a later reranking stage can inspect several candidates. Hit at one describes strict automatic success. Hit at ten describes whether the answer appears in a small review set. Mean reciprocal rank rewards systems that place the answer near the beginning while still distinguishing first place from later positions. Together these measures provide a fuller account of performance.

Careful interpretation is essential. An empirical threshold depends on the corpus, preprocessing rules, scoring model, search budget, and randomization protocol. It should not be presented as a universal constant. A negative result can arise because the search never generated the correct plaintext or because the language model preferred an incorrect candidate. Inserting the known plaintext into the final archive for diagnostic scoring helps distinguish these mechanisms without pretending that an operational decoder knew the answer.

Reproducibility requires more than publishing an average. A study should preserve trial level records, configuration files, random seeds, corpus identifiers, and software versions. It should freeze the main protocol after pilot calibration and retain unexpected outcomes. These practices make later comparisons meaningful and reduce the temptation to adjust parameters only after seeing the final curves.
